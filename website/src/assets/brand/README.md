from the Voice Pipes design system's assets (revision 1790921956-b57a). The Wrangler in boots and spurs comes from the
"Voice Pipes App · Sundown" canvas (revision 1790937768-cad3), which has him only inline: his 22 `<path>` elements are
copied verbatim from its History artboard into a plain `<svg>` wrapper.
